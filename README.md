# StageTap: Theatre Sound Cues

Native iPhone/iPad rehearsal sound cues by Sepideh Javanbakht Dalir / Arvinify. **In production; not submitted or released.** App Store identity6825117733 is accepted. TestFlight skipped by publisher instruction.

Prepare an ordered list of owned local audio, see the current/next cue and deliberately play one sound at a time. Stop holds the same cue; natural completion or Fade & next advances without autoplay. Rehearsal mode repeats a selected cue. A complete ZIP includes audio and restores as a fresh show.

Free:1show/10cues and portable backup. Lifetime Pro adds10shows,100cues/show and10cue-setting templates; audio is attached separately. Native AVAudioPlayer/session adapter, generation-checked transport, atomic manifests, streamed hashing, strict ZIP validation and verified StoreKit2 entitlements. No developer backend or analytics uploader.
